# Burger-Shop-Billing-System

A Java Swing-based GUI application designed for managing burger orders, customizing toppings, and generating bills.

Burger Selection: Choose from a variety of burgers.
Customization: Add sides like wedges, BBQ sauce, coke, and French fries.
Dynamic Pricing: Prices update based on selections and quantities.
Order Summary: Displays a detailed bill with order ID, customer name, date, and total payable amount.
Clear Functionality: Resets all fields to their default state.
